## WASAPI 独占与格式协商

- 新增 `src-tauri/src/audio/wasapi_exclusive.rs`：`windows` crate 直连 WASAPI，事件驱动独占、源采样率 / 位深协商（16 / 24-bit，44.1 / 48 / 96 kHz）、44.1k 的 128 帧对齐 dance（`AUDCLNT_E_BUFFER_SIZE_NOT_ALIGNED`）。
- 关键坑一：事件驱动独占的 `hnsBufferDuration` 与 `hnsPeriodicity` 必须都等于设备周期，传 0 会得到 `AUDCLNT_E_BUFFER_SIZE_ERROR 0x88890016`。
- 关键坑二：独占模式里 `GetCurrentPadding` 不可靠，轮询式实现会一直认为缓冲满；已改为事件驱动 + `IAudioClock` 定位。
- 关键坑三：本机 Realtek 端点初始化、Start 都成功，但只消费约一个缓冲后时钟停走（44.1 / 48 / 96k 均如此）。判断为驱动限制，引擎增加 900ms 推进校验，无进展则回退共享并显示原因。
- 界面新增输出模式切换（独占优先 / 共享），切换时保持播放位置；状态显示实际模式、输出位深 / 采样率与回退提示。
- 诊断命令：`audio_probe wasapi` 输出混合格式、独占格式支持矩阵与三类采样率的独占打开结果；`audio_probe engine` 覆盖加载、暂停、seek、恢复、模式切换与回退。
- 端到端（WebView2 CDP）：加载 44.1k 测试音频 → 独占尝试 → 0.9s 后回退共享 → 界面提示与三段参数正确 → 切共享后继续播放。
- 下一步：设备占用 / 热插拔恢复；换真实声卡复验独占推进；正式 SRC 与格式矩阵。

## M3：TTML / ASS / SYLT 卡拉OK

- 外置歌词新增 TTML：解析 `<p>` / `<span>` 的 begin/end/dur、clock-time 与 offset-time，span 逐字、同起点双语配对；ASS：解析 `[Events]` 的 Format/Dialogue、`\k` / `\kf` / `\K` / `\ko` 卡拉OK时长与 `\N`。
- 内嵌新增 SYLT：自研 ID3v2.2/2.3/2.4 帧读取（syncsafe、扩展头、unsync、压缩/加密跳过、v2.4 data-length/分组），支持毫秒与 MPEG 帧时间戳；同时支持 WAV 的 id3 chunk。
- 词间空格改为保留边缘空白；前端逐字进度用 `--word-progress` 渐变填充，卡拉OK当前词从已唱变为未唱。
- 实测：`audio_probe lyrics` 对 TTML/ASS 输出正确行、逐字与双语；构造带 SYLT 的 MP3 输出 2 行同步歌词；WebView2 CDP 验证歌词页 active 行与逐字进度（Kara 42%/53% 填充）。
- 未做：全局偏移、TTML `ttm:agent` 角色区分、ASS 绘图指令与复杂特效标签。

## M3：WSOLA 倍速与源时间轴映射

- 新增 `audio/tempo.rs`：WSOLA 时间伸缩（Hann 50% 重叠、归一化互相关搜索、按源采样率选择 1024–8192 窗口），保持音高；速度范围 0.5×–2.0×。
- 引擎链路改为 解码 → WSOLA（源采样率）→ rubato 重采样 → 环形缓冲；速度 1.0 完全旁路，不增加延迟。
- 快照位置改为 `base + 输出帧 / 输出采样率 × speed`，`frames_limit` 按 `剩余源时长 / speed × 输出采样率` 计算；前端两次状态事件之间也按 speed 推进，歌词与 CUE 继续使用源时间轴。
- 倍速切换保留源位置：清空环形缓冲、重置伸缩器、seek 回当前位置；前端持久化 `playbackSpeed` 并在加载新曲后继续生效。
- 实测：`audio_probe speed` 44.1k/96k 样本 1.5× 时源时间 1.2s 推进约 1.78s、0.5× 推进约 0.6s；单元测试校验 1.5×/0.75× 音高仍约 440 Hz、伸缩比例误差 < 8%；CDP 验证 1.5× 界面与位置推进。

## M3：独占无缝与 Bit-Perfect 判定

- `player_set_next` 不再只限共享链路：共享 / 独占都按当前输出格式打开下一轨，并预解码约 350ms 到 pending，换轨时原输出流继续消费同一环形缓冲。
- 独占输出新增 `exclusive_base`：换轨时前移已播帧数，倍速切换时前移当前已播帧数，保证 `played_samples` 始终表示当前分轨已播放帧数；修复独占换轨后位置跳到输出流绝对时间的问题。
- 新增 Bit-Perfect 判定：独占实际生效 + 采样率一致 + 声道一致 + 源位深与输出位深一致 + 倍速 1.0 + 音量 100% 才标记；共享混音、位深未知、重采样、DSP 均列出具体原因，不虚假标记。
- 前端新增 `BitPerfectPanel`（播放页紧凑、设置页完整三段参数与条件），左栏新增 0.5×–2.0× 倍速档位，播放控制区新增倍速循环按钮。
- 修复 `configure_output` 在模式切换 / 设备恢复后把分轨剩余帧限制重置为整段的问题：Session 记录 `current_offset`，按当前位置重算剩余输出帧。
- 实测：`audio_probe gapless` 共享链路 0–2s → 2–4s 切换后位置 0.26s、欠载不变、换轨后切 1.5× 正常；`recovery` / `engine` 通过；CDP 验证共享输出 verdict=unverifiable 且列出 4 条原因、设置页三段参数与原因列表可见。
