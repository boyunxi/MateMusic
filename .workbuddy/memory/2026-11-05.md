## M1 工程骨架与音频链路 spike

- 解码底座决策：用户拍板 **Symphonia 优先**。MVP 零 C 依赖、无 LGPL 分发负担；APE / WMA / DSD 与 `atempo` 推迟到 M3 由 FFmpeg 动态库补齐。
- 工程骨架：Tauri 2.12.5 + React 19 + TypeScript 7 + Vite 8 + Zustand；Rust 侧 `symphonia 0.5`（all features）、`cpal 0.15`。图标由脚本生成，无第三方素材。
